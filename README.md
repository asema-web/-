# Моя касса

Папа үчүн жөнөкөй сайт: адамдардын аттарын жана алган акчаларын жазат, суммасын өзү эсептейт, күн аягында даяр отчётту WhatsApp аркылуу жөнөтөт.

Сайттын ичи орус тилинде.

## Маанилүү: маалымат кайда сакталат

Бардык жазуулар папанын **телефонунда** (браузердин ичинде) сакталат. Интернет талап кылынбайт.
Бирок телефон жоголсо же браузердин маалыматы тазаланса, жазуулар жоголот.
Ошондуктан «Настройки» ичиндеги **«Сохранить резервную копию»** баскычын жумасына бир жолу басып, файлды WhatsApp'ка өзүңүзгө жөнөтүп коюңуз.

## 1. Компьютерде иштетүү

1. https://nodejs.org сайтынан Node.js (LTS версиясын) жүктөп орнотуңуз.
2. Бул папканы терминалда ачыңыз.
3. Төмөнкү буйруктарды бирден жазыңыз:

```
npm install
npm run dev
```

4. Терминалда чыккан даректи (адатта http://localhost:5173) браузерден ачыңыз.

## 2. Интернетке чыгаруу (акысыз)

1. Терминалда жазыңыз: `npm run build`
2. Бүткөндөн кийин `dist` деген папка пайда болот.
3. https://app.netlify.com/drop сайтына кирип, `dist` папкасын ошол жакка сүйрөп таштаңыз.
4. Netlify сизге даяр шилтеме берет. Ошону папага жөнөтөсүз.

Башка жолу: Vercel же GitHub Pages да иштейт.

## 3. Телефондун башкы экранына кошуу

**Android (Chrome):** сайтты ачыңыз, оң жактагы үч чекитти (⋮) басыңыз, «Добавить на главный экран» / «Установить приложение» дегенди тандаңыз.

**iPhone (Safari):** сайтты ачыңыз, «Поделиться» баскычын (чарчы жана жебе) басыңыз, «На экран "Домой"» дегенди тандаңыз.

## 4. Кандай иштейт

- Сайт ар күнү жаңы бош күндү өзү ачат (Бишкек убактысы боюнча). Эски суммалар жаңы күнгө өтпөйт.
- «Завершить день» басылса, күн бекилет. Жазууларды кокусунан өзгөртүү мүмкүн эмес.
- Эски күндү «История отчётов» → «Посмотреть отчёт» → «Исправить прошлый день» аркылуу оңдосо болот.
- «Поделиться в WhatsApp» баскычы даяр тексти менен WhatsApp'ты ачат. Кимге жөнөтүүнү папа өзү тандап, өзү басат.
- «Выгрузить историю для Excel» CSV файл берет.
